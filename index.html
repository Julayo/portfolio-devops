2 · delete-from.com — keyless CI/CD (OIDC)

Zero long-lived credentials: GitHub Actions federates into AWS via OIDC and assumes a scoped role at deploy time. Static hosting on S3 + CloudFront.

3 · Homelab — 3-node GitOps platform (on-prem)

One repo as source of truth across a workstation/AI server, a NAS and a public VPS. Nodes deploy by pulling from Git — no manual changes. 5-copy redundancy, Caddy + TLS, Tailscale mesh over CGNAT.
